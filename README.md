# 音符よみ

音符・休符の長さ、ドレミと日本の音名（ハニホ）・英語の音名（CDE）、ト音記号の楽譜の音の高さ、f・p・cresc.・Allegro・D.C. のような強弱・速さ・演奏のしかた・くり返しの記号を当てる1日5問のゲームです。楽譜が読めなくても、まちがえながら覚えられます。

- 遊ぶ：<https://satou-aaaaa.github.io/onpu-yomi/>
- 今日の5問はだれでも同じで1日1回。とことん・練習は何度でも遊べます。時間制限はありません。
- 記録は遊ぶ人のブラウザの中だけに残り、外へは送りません。

## 記号の意味の出典

- 強弱：英語版 Wikipedia「Dynamics (music)」 <https://en.wikipedia.org/wiki/Dynamics_(music)>
- 速さ：英語版 Wikipedia「Tempo」 <https://en.wikipedia.org/wiki/Tempo>
- くり返し・演奏のしかた・変化記号：英語版 Wikipedia「Glossary of musical terminology」 <https://en.wikipedia.org/wiki/Glossary_of_musical_terminology>
- 音符・休符の長さ・拍子は、4分音符を1拍とする数え方で計算しています。
- 学ぶ範囲：文部科学省 学習指導要領（平成29年告示）音楽の「音符、休符、記号や用語」。
